# Android Signing & Credentials Management

## 1. Overview

This document details credential management, production Android app signing keystores, EAS Organization configuration, and Google Play Console API service account integration for **Tally Ho**.

---

## 2. EAS Organization Account Setup

- **Account Type**: Expo Organization Account (`@garcia-ventures`).
- **Repository Connection**: GitHub Repository `Garcia-Ventures/TallyHo` linked directly to EAS Project.
- **Authentication**: `EXPO_TOKEN` stored in GitHub Repository Secrets.

---

## 3. Production Keystore Management

App signing for Android uses **EAS Credentials Manager** with **Google Play App Signing**.

### Keystore Generation & Storage

EAS handles keystore creation automatically on initial production build (`eas build --platform android --profile production`).

To view or manage keystore credentials:

```bash
bun x eas credentials --platform android
```

### Google Play App Signing

- Upload key: Keystore generated by EAS.
- App signing key: Managed securely by Google Play.
- Keystore credentials backup: Store encrypted copy in secure vault (e.g. 1Password / Google Secrets Manager).

---

## 4. Google Play Developer API Service Account

To enable automated store submissions via `eas submit`:

1. In Google Cloud Console, create Service Account for Google Play Console API.
2. Grant **Admin** or **Release Manager** permissions in Google Play Console (**Setup > API Access**).
3. Generate JSON Key File (`pc-api-key.json`).
4. Save key in EAS Secrets:

   ```bash
   bun x eas secret:create --name GOOGLE_SERVICES_JSON --type file --value ./pc-api-key.json
   ```
