# Reference: Store Metadata & Assets Specification

This reference document defines official store listing copy, keywords, categories, and screenshot dimensions for the **Google Play Store** and **Apple App Store**.

---

## 1. Google Play Store Metadata

- **App Name**: `TallyHo: Board Game Scorekeeper` _(34 / 50 characters)_
- **Short Description**: `Digital pencil & paper for game night. Track scores, rounds, and winners.` _(75 / 80 characters)_
- **Category**: Board / Card / Utility
- **Content Rating**: Everyone (ESRB / PEGI 3)

### Full Description

```text
TallyHo is your digital pencil and paper for game night.

Designed with an elegant, tactile paper-and-ink aesthetic, TallyHo eliminates messy paper pads, lost pens, and late-night math errors so everyone at the table can focus on the fun.

KEY FEATURES:
• Tactile Paper-and-Ink Design: Soft cream canvas with clean slate typography designed to look right at home next to physical boards and cards.
• Universal Scoring Models: Supports Race to Target (High Score wins like Rummy & Qwirkle), Race to Target (Low Score wins like Uno & Hearts), and Fixed Rounds (Trivia).
• Live Dynamic Margins: Real-time leaderboard highlighting point margins to the leader.
• Full Round History: Edit or correct past turns with a single tap.
• Quick Player Profiles: Customize colors and initials for your regular game night crew.
• Ad-Free Table Experience: Clean scorekeeping interface without intrusive mid-game banners.

Ditch the scrap paper. Upgrade your game night with TallyHo.
```
