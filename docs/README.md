## Overview of Tally Ho

**Tally Ho** is your digital pencil & paper for game night—a game-agnostic, paper-inspired scorekeeping app for mobile and web. Refer to [TallyHo.md](TallyHo.md) for full details on:

- Target audience and value proposition
- Universal gameplay and scoring mechanics (Race to Target High/Low, Fixed Rounds)
- Visual style, color palette, and haptic design specifications
